# class-plugins
ViewMembersWithRole (Kettu)

Port of the Vencord plugin [viewMembersWithRole](https://github.com/Ryfters/viewMembersWithRole).

## Usage
1. Open a server's ActionSheet (long-press the server / open server options).
2. Tap **View members with role**.
3. Select a role to see its members.

## Limitations
Discord's API only returns the first ~100 member IDs per role, plus members already in the client cache.
